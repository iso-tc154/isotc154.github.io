= ISO/TC 154 — www.isotc154.org

The committee website: an Astro 7 static site (Vue islands, Tailwind CSS 4),
deployed to GitHub Pages from `main` on every merge. The `/decisions/`
registry is rendered by `@edoxen/browser`; every other route is native Astro.

== Working here

Read link:CLAUDE.md[CLAUDE.md] — it documents the commands
(`pnpm build` / `pnpm test` / `pnpm validate`), the module map under
`src/lib/`, the build-time data pipeline, the `resolutions-data` submodule
flow, and the conventions that keep the 1,100-page build honest.

image:https://github.com/isotc154/isotc154.github.io/actions/workflows/build_deploy.yml/badge.svg["build_deploy", link="https://github.com/isotc154/isotc154.github.io/actions/workflows/build_deploy.yml"]

== Layout

[cols="1,3"]
|===
|`src/` |Pages, layouts, components, and the `src/lib/` deep modules
|`scripts/` |The build-time data pipeline (build-data, generate-edoxen-events, validators)
|`_data/` |Hand-maintained source data + the `resolutions` submodule
|`data/` |The canonical xlsx-derived meetings list
|`content/` |AsciiDoc pages and posts
|`attic/` |Retired Jekyll/Vue trees (moved, not deleted — never referenced by the build)
|===
